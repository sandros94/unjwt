# Sign and verify

> Sign claims with a key so the receiver can tell who issued them and that nobody changed them.

A signed token (a JWS) is a letter with a signature across the flap. Anyone who holds it can read the letter, but only the holder of the signing key could have made that signature, and changing a single character breaks it. That's what signing gives you: the receiver knows who issued the claims and that they arrived exactly as written. It doesn't give you privacy. The payload is base64url text that anyone can decode, so never put a secret or personal data in it; [encrypt](/jwe) when the content must stay hidden. [Concepts](/getting-started/concepts) has the vocabulary if JWS, JWK and claims still blur together.
