# Quickstart

> Five short programs with the output each one printed, from a signed token to a cookie session.

The first four snippets are complete programs. The comment after each call is what it returned when run. Random values (keys, tokens, thumbprints) are cut short with `…`.

## Sign and verify a token

```ts
import { sign, verify, isJWTError } from "unjwt/jws";
import { generateJWK } from "unjwt/jwk";

const key = await generateJWK("HS256");
// { alg: "HS256", ext: true, k: "aV1kaiMK…", key_ops: ["sign", "verify"], kty: "oct", kid: "gOyc7uMK…" }

const token = await sign({ sub: "user_1", role: "admin" }, key, { expiresIn: "1h" });
// "eyJraWQiOiJnT3ljN3VNS2tQNTFTRDgy…"

const { payload, protectedHeader } = await verify(token, key);
// payload:         { sub: "user_1", role: "admin", iat: 1792068434, exp: 1792072034 }
// protectedHeader: { kid: "gOyc7uMK…", alg: "HS256", typ: "JWT" }

try {
  await verify(token, await generateJWK("HS256"));
} catch (error) {
  if (isJWTError(error)) console.log(error.code);
  // "ERR_JWS_SIGNATURE_INVALID"
}
```

`expiresIn` added `iat` and `exp`. `verify` read the algorithm from the key, checked the signature, then checked `exp`.

## Type the claims and check who issued them

```ts
import { sign, verify, isJWTError } from "unjwt/jws";
import { generateJWK } from "unjwt/jwk";
import type { JWTClaims } from "unjwt";

interface MyClaims extends JWTClaims {
  sub: string;
  role: "admin" | "member";
}

const key = await generateJWK("HS256");

const token = await sign(
  { sub: "user_1", role: "member", iss: "https://auth.example.com", aud: "api" },
  key,
  { expiresIn: "15m" },
);

const { payload } = await verify<MyClaims>(token, key, {
  issuer: "https://auth.example.com",
  audience: "api",
  maxTokenAge: "1h",
});
// payload.role: "member"
// payload: { sub: "user_1", role: "member", iss: "https://auth.example.com", aud: "api", iat: 1792068792, exp: 1792069692 }

try {
  await verify(token, key, { audience: "billing" });
} catch (error) {
  if (isJWTError(error)) console.log(error.code, error.message);
  // ERR_JWT_CLAIM_INVALID Invalid JWT "aud" (Audience) Claim: Expected billing, got api
}

const yesterday = new Date(Date.now() - 24 * 60 * 60 * 1000);
const stale = await sign({ sub: "user_1" }, key, { expiresIn: "1h", currentDate: yesterday });

try {
  await verify(stale, key);
} catch (error) {
  if (isJWTError(error, "ERR_JWT_EXPIRED")) console.log(error.code, error.cause.exp);
  // ERR_JWT_EXPIRED 1791985992
}
```

The type argument names the shape of `payload`; the runtime check is the options. `issuer`, `audience` and `maxTokenAge` each make their claim required. `ERR_JWT_EXPIRED` carries the token's `jti`, `iat` and `exp` in `error.cause`.

## Encrypt and decrypt

```ts
import { encrypt, decrypt } from "unjwt/jwe";
import { generateJWK } from "unjwt/jwk";

// With a password: PBES2, 600 000 PBKDF2 iterations
const sealed = await encrypt({ card: "4242", exp_month: 12 }, "correct horse battery staple");
// "eyJwMmMiOjYwMDAwMCwicDJzIjoiWlBiZm1FYkNn…"

const opened = await decrypt(sealed, "correct horse battery staple");
// opened.payload:         { card: "4242", exp_month: 12 }
// opened.protectedHeader: { p2c: 600000, p2s: "ZPbfmEbC…", alg: "PBES2-HS256+A128KW", enc: "A256GCM", typ: "JWT" }

// With a generated key
const key = await generateJWK("A256KW");
// { alg: "A256KW", ext: true, k: "wdy5WeH-…", key_ops: ["wrapKey", "unwrapKey"], kty: "oct", kid: "yxSRM0ov…" }

const token = await encrypt({ sub: "user_1" }, key);
const { payload, protectedHeader } = await decrypt(token, key);
// payload:         { sub: "user_1" }
// protectedHeader: { kid: "yxSRM0ov…", alg: "A256KW", enc: "A256GCM", typ: "JWT" }

const note = await encrypt("plain text works too", key);
const text = await decrypt(note, key, { payload: "string" });
// text.payload: "plain text works too"
```

A string key is a password, and a password always means PBES2. `enc` defaults to `A256GCM`. A text payload needs `payload: "string"` on the way back; without it `decrypt` expects a JSON object and throws `ERR_JWE_INVALID`.

[More on encrypting](/jwt/jwe/encrypt) · [More on decrypting](/jwt/jwe/decrypt)

## Generate, export and import a key

```ts
import { generateJWK, generateKey, exportKey, importKey, thumbprint } from "unjwt/jwk";
import type { JWK_EC_Public } from "unjwt/jwk";
import { sign, verify } from "unjwt/jws";

// A JWK pair; the kid defaults to the RFC 7638 thumbprint
const { privateKey, publicKey } = await generateJWK("ES256");
// publicKey: { crv: "P-256", ext: true, key_ops: ["verify"], kty: "EC", x: "jCnHHH6d…", y: "KgD5YSRC…", alg: "ES256", kid: "Uuln-eV9…" }
privateKey.kid === publicKey.kid; // true
(await thumbprint(publicKey)) === publicKey.kid; // true

// A CryptoKey pair, exported to a JWK and imported back
const pair = await generateKey("ES256");
const exported = await exportKey<JWK_EC_Public>(pair.publicKey);
// { crv: "P-256", ext: true, key_ops: ["verify"], kty: "EC", x: "rYvYaTZZ…", y: "3-Il0qLu…" }

const published = { ...exported, alg: "ES256" as const, kid: await thumbprint(exported) };
// { …exported, alg: "ES256", kid: "fUh-ToLU…" }

const verifyKey = await importKey(published);
// CryptoKey { type: "public", algorithm: { name: "ECDSA", namedCurve: "P-256" }, … }

const token = await sign({ sub: "user_1" }, pair.privateKey, {
  alg: "ES256",
  protectedHeader: { kid: published.kid },
});
await verify(token, published);
// { payload: { sub: "user_1" }, protectedHeader: { kid: "fUh-ToLU…", alg: "ES256", typ: "JWT" } }
await verify(token, verifyKey);
// { payload: { sub: "user_1" }, … }
```

Web Crypto exports an EC key without `alg` or `kid`, so the program adds both before publishing it. A `CryptoKey` carries no JOSE algorithm, which is why `sign` takes `alg` here and not in the first program.

## Keep a session in a cookie (H3 v2)

This one is a server, so it does not run in isolation. Start it and call the three routes from a client.

```ts
import { H3, serve } from "h3";
import { defineJWESession, generateJWK } from "unjwt/adapters/h3v2";

// Generate once and load it from your secret store in production
const key = await generateJWK("A256KW");

const useSession = defineJWESession({
  key,
  name: "__Host-session",
  maxAge: "7D",
});

const app = new H3()
  .post("/login", async (event) => {
    const session = await useSession.use(event);
    await session.update({ userId: "user_1" });
    return { id: session.id, expiresAt: session.expiresAt };
  })
  .get("/me", async (event) => {
    const session = await useSession.use(event);
    if (!session.id) return { signedIn: false };
    return { signedIn: true, userId: session.data.userId };
  })
  .post("/logout", async (event) => {
    const session = await useSession.use(event);
    await session.clear();
    return { signedIn: false };
  });

serve(app);
```

`/login` answers with a fresh `id` and sets `__Host-session` as an encrypted token, `HttpOnly; Secure; SameSite=Lax`, expiring in seven days. `/me` reads it back. `/logout` overwrites it with `Max-Age=0`. A session stays empty until the first `update()`, so `/me` without a cookie returns `{ signedIn: false }`.
