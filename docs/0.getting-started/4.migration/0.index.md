# Migration guides

> Upgrade across a breaking release: one guide per version, with every change and the edit it asks for.

Open the guide for the version you're moving to. You don't have to read all of it: work through the sections that name a function or option you use. Moving across two releases, such as 0.7 to 0.9, take the guides in order.

- [Migrate from 0.8 to 0.9](/getting-started/migration/to-0.9): sessions through `unjwt/session` in place of the h3 adapters, symmetric JWE session keys, safer cookie defaults, and the removed aliases
- [Migrate from 0.7 to 0.8](/getting-started/migration/to-0.8): declared payload modes, keys instead of strings, options objects, stricter sessions and token checks
