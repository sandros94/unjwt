# Migration guides

> One guide per breaking release, listing every change and the edit it asks for.

Pick the guide for the version you are moving to. Each one is self-contained. Work through the sections that name a function or option you use; anything not listed behaves as before.

::card-group
::card{title="Migrating to 0.8" icon="i-lucide-arrow-right-left" to="/getting-started/migration/to-0.8"}
From 0.7.x: declared payload modes, key material only, public JWK Sets, options objects, stricter sessions and wire checks, and the move to `unjwt/internal`.
::
::card{title="Migrating to 0.9" icon="i-lucide-arrow-right-left" to="/getting-started/migration/to-0.9"}
From 0.8.x: one session definition per family in place of the per-call session functions, and a named session header.
::
::
