# Encrypt and decrypt

> Encrypt claims or data so only the holder of the right key can read them, and any change makes the token fail to open.

An encrypted token (a JWE) is a locked box. Each token gets a fresh random key that locks the content, and that key is itself locked for the recipient: with a key you share, with the recipient's public key, or with a key derived from a password. The recipient unlocks the small key, then the box, and the box's seal breaks if anyone changed a byte on the way. Unlike a [signed token](/jws), nobody on the path can read the content. What a JWE made with a public key doesn't tell you is who sent it, since anyone holding that public key can lock a box; [sign, then encrypt](/jwe/encrypt#sign-then-encrypt) when the sender matters. [Concepts](/getting-started/concepts) has the vocabulary.
