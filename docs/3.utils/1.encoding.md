# Encoding

> Strict base64url and base64 codecs with the JOSE and PEM rules fixed in, plus the byte, text and randomness helpers that go with them.

```ts
import { base64UrlParse, base64UrlStringify } from "unjwt/utils";

base64UrlStringify('{"alg":"HS256","typ":"JWT"}'); // "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9"
base64UrlParse("aGVsbG8"); // "hello"
```

Every segment of a JWT is base64url text, and every PEM body is standard base64. These are the codecs `verify()`, `decrypt()` and `importPEM()` apply, with the alphabet and padding rules fixed, so you cannot call them with a policy that disagrees with the one the library enforces.

## Signatures

```ts
function base64UrlStringify(data: string | Uint8Array): string;
function base64UrlParse(
  text: string,
  options?: { returnAs?: "string" | "uint8array" | "bytes" },
): string | Uint8Array<ArrayBuffer>;

function base64Stringify(data: string | Uint8Array): string;
function base64Parse(
  text: string,
  options?: { returnAs?: "string" | "uint8array" | "bytes" },
): string | Uint8Array<ArrayBuffer>;
```

A `string` passed to a `*Stringify` function is UTF-8 encoded first. A `*Parse` function reads a `string`; without `returnAs` it returns a UTF-8 `string`, which must be valid UTF-8, and `"uint8array"` or its alias `"bytes"` returns the raw bytes.

| Function             | Alphabet           | Padding                 |
| -------------------- | ------------------ | ----------------------- |
| `base64UrlStringify` | URL-safe `-_`      | never written           |
| `base64UrlParse`     | URL-safe `-_` only | any `=` is rejected     |
| `base64Stringify`    | standard `+/`      | always written          |
| `base64Parse`        | standard `+/` only | the `=` run is required |

The URL-safe pair follows [RFC 7515 §2](https://www.rfc-editor.org/rfc/rfc7515#section-2): no padding, no whitespace, no line breaks. The standard pair follows [RFC 4648 §4](https://www.rfc-editor.org/rfc/rfc4648#section-4) and is the one PEM bodies use.

```ts
import { base64Parse, base64Stringify, base64UrlParse, base64UrlStringify } from "unjwt/utils";

base64UrlStringify("hello"); // "aGVsbG8"
base64UrlStringify(new Uint8Array([255, 255])); // "__8"
base64Stringify("hello"); // "aGVsbG8="
base64Stringify(new Uint8Array([255, 255])); // "//8="

base64UrlParse("aGVsbG8"); // "hello"
base64UrlParse("aGVsbG8", { returnAs: "bytes" }); // Uint8Array(5) [104, 101, 108, 108, 111]
base64Parse("aGVsbG8="); // "hello"
```

When the decoded bytes are not text, ask for bytes. Decoding `"__8"` to a string throws, because `0xFF 0xFF` is not UTF-8.

```ts
base64UrlParse("__8", { returnAs: "bytes" }); // Uint8Array(2) [255, 255]
base64UrlParse("__8");
// UnsecureError MALFORMED: Base64Url.parse: decoded bytes are not valid UTF-8.
```

## Strict by default

`parse` accepts only the canonical encoding of a byte string. Two different texts that decode to the same bytes are how signature checks get bypassed, so anything else is refused. There is no lenient mode: token material never goes through one, and a value a person pasted is cleaned by the application before it is decoded.

```ts
base64UrlParse("aGVsbG8=");
// UnsecureError MALFORMED: Base64Url.parse: expected 0 "=" padding characters, found 1.
base64UrlParse("a+Vs");
// UnsecureError MALFORMED: Base64Url.parse: invalid character "+" at index 1.
base64UrlParse("aGVs bG8");
// UnsecureError MALFORMED: Base64Url.parse: invalid character " " at index 4.
base64UrlParse("aGVsbG9");
// UnsecureError MALFORMED: Base64Url.parse: the last symbol sets bits past the final byte.
base64Parse("aGVsbG8");
// UnsecureError MALFORMED: Base64.parse: expected 1 "=" padding characters, found 0.
base64Parse("__8=");
// UnsecureError MALFORMED: Base64.parse: invalid character "_" at index 0.
```

## Bytes and text

`concatUint8Arrays(...arrays)` joins byte arrays into one new buffer. `maybeArray(value)` wraps a value in an array unless it already is one. `textEncoder` and `textDecoder` are shared module-level instances from `unsecure/utils`, so you do not allocate one per call.

```ts
import {
  base64UrlStringify,
  concatUint8Arrays,
  maybeArray,
  textDecoder,
  textEncoder,
} from "unjwt/utils";

const signingInput = concatUint8Arrays(
  textEncoder.encode(base64UrlStringify('{"alg":"HS256"}')),
  textEncoder.encode("."),
  textEncoder.encode(base64UrlStringify("hi")),
);
textDecoder.decode(signingInput); // "eyJhbGciOiJIUzI1NiJ9.aGk"

concatUint8Arrays(new Uint8Array([1, 2]), new Uint8Array([3])); // Uint8Array(3) [1, 2, 3]
maybeArray("api"); // ["api"]
maybeArray(["api", "web"]); // ["api", "web"]
```

## secureRandomBytes()

`secureRandomBytes(length)` returns `length` bytes from the platform CSPRNG. It is the [`unsecure/random`](https://unsecure.s94.dev/generate/random) function, re-exported unchanged. Use it for salts, IVs and raw secrets, never `Math.random()`.

```ts
import { base64UrlStringify, secureRandomBytes } from "unjwt/utils";

const salt = secureRandomBytes(16); // Uint8Array(16)
base64UrlStringify(salt); // "HZVurVz1r5er…"

secureRandomBytes(-1);
// UnsecureError OUT_OF_RANGE: secureRandomBytes: length must be an integer between 0 and 2147483647, got -1.
```

## digestUrl()

`digestUrl(data, hash?)` returns the base64url digest of text (as UTF-8) or bytes under `"SHA-256"`, `"SHA-384"` or `"SHA-512"`, SHA-256 by default.

```ts
function digestUrl(
  data: string | Uint8Array,
  hash?: "SHA-256" | "SHA-384" | "SHA-512",
): Promise<string>;
```

A DPoP proof uses two SHA-256 values: `cnf.jkt` identifies the client's public key, and `ath` identifies the exact access token accompanying the proof.

```ts
import { thumbprint } from "unjwt/jwk";
import { digestUrl } from "unjwt/utils";

const jkt = await thumbprint(publicKey);
const ath = await digestUrl(accessToken);
```

[`unjwt/dpop`](/dpop) creates and verifies these proofs, including the method, URL, time, nonce and token checks. The digest helpers remain available for composing other protocols.

## Errors

These helpers come from `unsecure` and throw its `UnsecureError` directly, not a `JWTError`.

| Cause                                                                          | `code`         |
| ------------------------------------------------------------------------------ | -------------- |
| Text that is not the canonical encoding, or a decoded string that is not UTF-8 | `MALFORMED`    |
| A value that is neither text nor bytes, such as `null`                         | `INVALID_TYPE` |
| A `secureRandomBytes` length that is negative, fractional or too large         | `OUT_OF_RANGE` |

Check with [`isUnsecureError`](/utils/guards#isunsecureerror) imported from unjwt. unjwt bundles its own copy of `unsecure`, so an `UnsecureError` class imported from your own `unsecure` dependency is a different class and `instanceof` against it never matches.
